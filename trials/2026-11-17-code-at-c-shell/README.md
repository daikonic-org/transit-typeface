# Round c-shell at study

Local design trial; not installed or adopted. Previous trials and installed Code1.021 are preserved.

The outer curve follows the round structure and proportions of Metropolitan Line c, redrawn as cubic arcs to merge directly into the original two-storey a upper arch. It is not a union of overlapping letters. The lower terminal aligns with the a right stem. The original a bowl/counter/right stem are uniformly scaled to85%, without selective horizontal stretching. Outer bounds at Book are505x619, centered around the lowercase o; the shell extends above and below o. Fixed shell size is620units tall approximately; a is reduced to fit rather than increasing shell size for a.

Book.png/PDF compares previous short wrap (left) with the new construction (right). NamedWeights shows Light300, Book350, Regular400. SVG files are editable outline proofs. The Python recipe uses the repository shared build, weight and proof helpers.
