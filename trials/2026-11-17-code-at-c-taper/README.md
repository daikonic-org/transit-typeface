# c-to-a thickness transition

The descending fragment of the a upper hook is removed. The c inner upper arc now joins directly into the a inner arch, eliminating the former patch of overlapping thickness. Outer silhouette, bowl, stem, advance and alignment remain unchanged.

Book comparison: previous join; gradual nominal95-unit c to82-unit a-arch transition; nominal uniform82-unit c option. These are optical curve constructions, not exact mathematical offset curves. The tapered middle option is compiled as a separate VF and Light/Book/Regular snapshots; uniform is a Book design comparison. All earlier trials and installed1.021 are preserved.
